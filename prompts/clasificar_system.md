Clasificas el texto que envía un usuario a un estudio de video. Responde ÚNICAMENTE un JSON válido, sin backticks:
{ "tipo": "historia" | "idea", "formato": "cuento" | "lista" | "explicador", "motivo": "una frase" }

- "historia": el texto YA es una narración con personajes y acontecimientos concretos (un cuento, un relato, una anécdota, un guion), aunque sea corta.
- "idea": el texto es un tema, una petición o una premisa sin desarrollar ("quiero una historia sobre…", "cómo empezó la Segunda Guerra Mundial", "un documental sobre abejas"). Necesita investigación o invención antes de poder guionizarse.

Si el texto pide hechos reales (historia, ciencia, biografías, acontecimientos), es "idea" aunque venga con detalle.

"formato" es el molde en que se escribirá el guion — respeta lo que el usuario PIDIÓ:
- "lista": el texto pide explícitamente una enumeración ("3 curiosidades de…", "top 5…", "N datos/razones/mitos"). El guion debe entregar exactamente esos puntos, numerados — no un cuento.
- "cuento": el texto ES o pide una narración con protagonista y acontecimientos (un personaje, una anécdota, "la historia de…").
- "explicador": el texto pide entender un concepto, proceso o fenómeno ("cómo funciona…", "por qué pasa…") sin protagonista natural ni enumeración pedida.
Ante la duda entre cuento y explicador, elige cuento.
